# LaTeX/Word review fixtures

Fixtures for `calkit/tests/test_docx.py`, all made from the paper in
`main.tex` and `methods.tex`.

## Made by hand in Word on macOS

These can't be regenerated by a script, since Word's PDF import and editing
were done interactively.

- `word-import.docx`: Word's own import of the compiled paper's PDF, i.e.,
  what `calkit.docx.pdf_to_docx` produces. The tests stand it in for Word so
  they run anywhere.
- `export.docx`: the output of `calkit latex to-docx` from that import.
- `returned.docx`: `export.docx` with a reviewer's tracked edits and a
  comment, saved in Word.
- `accepted.docx`: `returned.docx` after accepting every change in Word.
- `resolved.docx`: `accepted.docx` with the exported comment thread marked
  resolved.

These were exported before equations were converted from the source, so
they carry Word's own rendering of the equation.

## Made by script in LibreOffice

- `libreoffice-returned.docx`: an export, with its equation converted by
  Pandoc, that LibreOffice edited with changes tracked: a sentence edit, a
  comment, and `C_T` changed to `C_P` in the equation. LibreOffice doesn't
  track changes inside equations, so that one isn't pending.
- `libreoffice-accepted.docx`: the same after accepting all changes.

To regenerate them, with LibreOffice installed, run from the repo root:

```sh
uv run python test/docx/make-libreoffice-fixtures.py
```

The script exports the paper as the tests do, then drives LibreOffice with a
Basic macro in a temporary profile, so it doesn't touch your own settings.
