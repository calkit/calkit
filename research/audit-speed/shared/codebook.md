# Codebook: participants.csv

| Column           | Description                                            |
| ---------------- | ------------------------------------------------------ |
| `participant_id` | Participant identifier                                 |
| `condition`      | Randomized condition: `treatment` or `control`         |
| `age`            | Age in years at enrollment (eligible range 18–65)      |
| `ses_code`       | Self-reported SES: 1 = low, 2 = middle, 3 = high, 9 = not reported |
| `outcome`        | Outcome score at follow-up                             |
